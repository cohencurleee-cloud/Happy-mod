# HappyMod UI

Static front-end UI concept inspired by the HappyMod mobile interface.

- Scrollable mobile-first layout
- Featured / Game / App tabs
- Search
- Category filters
- App cards and fake download buttons
- 100% Working / Mini Games bottom navigation
- Side drawer
- No real APK or mod downloads

## Vercel

This repo is static and can be deployed directly to Vercel with no build command.
